# V4 — Parcours simplifié (2026-09-26)

Décidé après revue de tous les prompts et workflows V3. Objectif : un formulaire, 2 prompts, une annonce type Vinted.

## Parcours

Formulaire unique :
- **Input** : photo du produit.
- **Inspi** : choisir dans le dossier Drive `inspis` ou en uploader une (image brute, aucune indexation).
- **Mannequin** : description texte modifiable. Toute modification est **sauvegardée** comme nouveau défaut (global).
- **Pose** : vide par défaut. Vide = le modèle s'inspire de l'inspi. **Reset à chaque run.**
- **Indications écrites** : optionnelles, reset à chaque run.
- **Taille, marque, mesures** : optionnels, texte libre, réservés à `prompt_texte`.
- **N** : nombre d'images du lot, réglage user (défaut 3, min 1, max 6).

Flux :
1. « Générer » → image **test** (= image n°1 du lot).
2. Feedback général (« un peu moins foncé ») → le test est regénéré avec le feedback, on reboucle. Le feedback est une variable de `prompt_image`, resetée au run suivant, conservée dans l'historique.
3. Validation du test → **N-1 images** en parallèle et **texte d'annonce** automatique, en parallèle.
4. Lancement refusé si le coût estimé (tentatives × coût unitaire) dépasse le plafond journalier restant.
5. Une relance automatique par image en échec, sans bloquer les autres.

Sortie : aperçu façon annonce Vinted (photos, titre, description), texte éditable, « régénérer le texte », « copier le texte », « télécharger les images ». Pas de publication automatique.

## Prompts (2, visibles, éditables, versionnés avec note et restauration)

- `prompt_image` : mannequin + pose + inspi (image de référence) + input + indications + feedback. Un appel modèle image, pas de LLM intermédiaire, pas de JSON produit.
- `prompt_texte` : photo input d'origine + taille/marque/mesures/indications → titre et description.

`config_mannequin` (description) est une valeur éditable, pas un prompt.

## Gardé

Historique avec coûts (un run = réglages, versions de prompt, images, texte, feedbacks, coût), plafond journalier (`config_plafond`), versionnage, journal Drive, chien de garde (erreurs/fiches bloquées), sauvegarde manuelle. Anciens runs V3 en lecture seule, sans migration.

## Supprimé

JSON produit, `moods_liste`, `cadrages`, `indexation_photo`, `selection_style`, `brief_*`, `check_fidelite`, `config_mannequins`, `config_feedback`, `meta_*`/`config_ajustement`, profils user, thumbs/raisons, « garder un plan », bibliothèque indexée.
